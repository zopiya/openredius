## 二、维度 1 — 全功能端到端

**方法**:Playwright(http 模式)自动化 + 后端 pytest 补点 + 数据面断言。

每条功能点走**五段链路**:
`UI 触发 → HTTP 请求(200/4xx 符合契约) → DB 状态变更 → audit_log 落库 → UI 反馈(toast/列表刷新)`。

**自动化覆盖**:
1. 扩展 `scripts/e2e.mjs` 为 http 模式:登录真实账号 → 逐页逐功能操作 → 断言。
2. 每个 ★ 写操作:操作前抓取 DB 快照 → 操作 → 操作后比对(如 users 停用后 radcheck 增加 `Auth-Type := Reject`、status 变更)。
3. 导出类:断言响应头 Content-Type/Content-Disposition + 文件非空 + 含关键字。
4. 深链/锚点:13 路由 + 参数预填生效。

## 三、维度 2 — 全角色全工作流审计

**方法**:RBAC 越权矩阵(自动化)+ SOP 走查(人工/脚本)+ 审计日志核对(自动化)。

### 3.1 三角色 SOP 工作流

- **admin**:登录→仪表盘→用户(启停/分配策略/AD 同步)→策略(CRUD/重排/下发)→设备(NAS/Secret/终端/证书)→设置(RADIUS/AD/告警/证书/管理员/角色授权)→审计日志→报表导出。
- **operator**:登录→仪表盘/会话/日志查看→强制下线→用户启停/分配策略→AD 同步→报表导出。
- **auditor**:登录→仪表盘/会话/日志/报表查看与导出→审计日志查询。

### 3.2 RBAC 越权矩阵(每格断言:前端不可见 + 后端 403)

| 能力 | admin | operator | auditor |
|---|---|---|---|
| 强制下线 POST /sessions/disconnect | 200 | 200 | 403 |
| 用户启停/分配策略/AD 同步 | 200 | 200 | 403 |
| 策略 CRUD/重排 | 200 | 403 | 403 |
| 设备 CRUD/Secret 明文 | 200 | 403 | 403 |
| 系统设置/管理员账户 | 200 | 403 | 403 |
| 审计日志查询 | 200 | 403 | 200 |
| 只读资源(dashboard/sessions/logs/reports) | 200 | 200 | 200 |

### 3.3 审计日志完整性

对照 docs/08 必记事件清单逐条断言:`登录(成/败) / 强制下线 / 用户启停·策略分配 / 策略 CRUD / 设备 CRUD / Secret 查看·修改 / 设置变更 / AD 同步 / 管理员账户变更 / radius reload`。
断言字段:actor、action(点分动词)、target_type/target_id、detail_json、ip、时间。

### 3.4 已知疑点(重点排查)

- 前端**无独立审计日志页**,auditor 的"审计日志查询"入口是否可达?
- Secret 明文查看是否必写 `secret.reveal` 审计、是否仅 admin 可见、掩码规则(前4后4)。
- 改密后旧 refresh 作废(admin 在 Settings 改他人/自己密码)。

## 四、维度 3 — 交互体验

**方法**:启发式评估清单(人工走查 + 截图)+ 一致性 grep 断言。

1. **反馈**:每个操作有 loading / 成功 toast / 失败提示;错误信息可读(非裸堆栈)。
2. **防误操作**:危险操作(下线/停用/删除/吊销/reload/角色变更)均有二次确认 + 影响说明。
3. **三态**:每页空态(空数据引导)、错误态(请求失败可重试)、加载态(skeleton/spin)。
4. **一致性**:文案统一(菜单名↔页面名↔PageHeader)、颜色/token 无回退、按钮层级语义正确。
5. **高效**:筛选可清空、分页/排序合理、常用操作 ≤3 次点击、深链可分享。
6. **可访问性**:表单 label 关联、按钮可键盘触发、对比度达标。
7. **回归守卫**:`grep` 断言无 #0071e3/#1d1d1f 等硬编码回退、inline style 数量 ≤40、radius-admin.css ≤40 行。

## 六、并行编排

- 三条线**可并行**:维度 1(自动化)、维度 2(越权矩阵+审计核对)、维度 3(交互走查)。
- 每条线内:Playwright 与 pytest 并行;人工走查与自动化互不阻塞。
- 用 subagent 并行派发(隔离上下文),每轮汇总到报告。
- 数据面断言(DB/audit_log)与 UI 断言在同一自动化脚本内串行,保证因果顺序。
